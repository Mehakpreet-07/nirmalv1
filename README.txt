MASTER CRAFTSMAN CONSTRUCTION LTD. — STATIC WEBSITE

Files:
- index.html
- projects.html
- contact.html
- assets/css/styles.css
- assets/js/main.js

HOW TO RUN
1. Extract the folder.
2. Double-click index.html, or open the folder in VS Code and use Live Server.

RESPONSIVE
The CSS includes desktop, laptop/tablet, and mobile breakpoints.
- Desktop: full navigation / 3-column grids
- Tablet: 2-column project layouts / responsive nav
- Mobile: menu button / 1-column sections / full-width forms

REUSABLE STRUCTURE
Header, footer, project data, strengths, services, qualifications, categories and project cards are all generated from assets/js/main.js.
To change content later, update the siteData object instead of editing every HTML page.

DUMMY IMAGES
The project images use public Unsplash URLs as temporary placeholders. Replace them with real project photographs later.

CONTACT FORM
This is a front-end-only HTML/CSS/JS website. The form validates correctly but does not send email until you connect it to:
- Formspree
- Netlify Forms
- EmailJS
- PHP
- or your own backend endpoint

IMPORTANT
The visible project text is based on the corrected resume images supplied in the conversation.
